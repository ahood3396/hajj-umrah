# رفيق الحاج والمعتمر 🕋

دليل تعليمي تفاعلي للعمرة والحج مع عدّاد للطواف والسعي.

## المميزات
- شرح العمرة والحج خطوة بخطوة من مصادر موثوقة
- عدّاد تفاعلي للطواف (7) والسعي (7) مع حفظ تلقائي
- مظهر نهاري وليلي + تحكم بحجم الخط
- متجاوب بالكامل مع الجوال

## التشغيل محلياً
افتح ملف `index.html` في المتصفح.

## النشر
الموقع منشور عبر GitHub Pages من فرع `main`.
